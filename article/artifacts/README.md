# Article experiment artifacts

Generated by `make experiment-jev-article`.

| File | Purpose |
|------|---------|
| `jev_responses.jsonl` | Full input state + marketing response per row for article snippets |
| `jev_latency_summary.json` | Aggregate latency stats (cold start, p50, p95, total) |

The harness also writes `raw.jev_benchmark_runs` in `jaffle_shop.duckdb` for
`analyses/jev_latency_summary.sql`.

These files are gitignored. Re-run the harness after changing the sample size or
marketing questions.
